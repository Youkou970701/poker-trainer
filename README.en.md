# Poker Trainer

[中文](README.md) · **English** · [日本語](README.ja.md)

A single-file Texas Hold'em drill book for the browser. Open it on your phone and start practicing.

👉 **[Play online](https://youkou970701.github.io/poker-trainer/)** (English / 中文 / 日本語)

- **Poker math**: pot odds, outs, MDF (minimum defense frequency)
- **Preflop opening**: should you open-raise this hand from this seat?
- **Short-stack push/fold**: shove or fold with a short stack in tournaments
- **Range chart**, **glossary flashcards**, **stats** with your recent mistakes

The opening ranges are an approximate GTO baseline for a 6-max table at 100bb. They're meant to build intuition, not to replace a solver. Push/fold answers are estimated from hand ranking and stack depth; for borderline hands, both choices count as correct.

Pure static: one `index.html`, no dependencies, no backend. Double-click to open, or host it on any static site host. Your progress is stored only in your browser.
