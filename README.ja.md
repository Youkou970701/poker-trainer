# ポーカートレーナー

[中文](README.md) · [English](README.en.md) · **日本語**

ブラウザで動く、ファイル 1 つだけのテキサスホールデム問題集です。スマホで開けばすぐに練習できます。

👉 **[オンラインで試す](https://youkou970701.github.io/poker-trainer/)**（日本語 / English / 中文）

- **ポーカーの数学**：ポットオッズ、アウツ、MDF（最小ディフェンス頻度）
- **プリフロップのオープン**：このポジションでこのハンドをオープンレイズすべきか
- **ショートスタックのプッシュ／フォールド**：トーナメントでショートスタック時にオールインかフォールドか
- **レンジ表**、**用語フラッシュカード**、最近のミスを確認できる**成績**

オープンレンジは 6 人テーブル・100bb を想定したおおよその GTO ベースラインです。感覚をつかむためのもので、ソルバーの代わりではありません。プッシュ／フォールドの正解はハンドの強さの順位とスタックの深さから見積もっており、ボーダーラインのハンドはどちらを選んでも正解になります。

完全な静的ページです。`index.html` 1 つだけで、依存ライブラリもバックエンドもありません。ダブルクリックで開くか、任意の静的ホスティングに置いてください。学習の記録はブラウザの中にだけ保存されます。
