# 德扑训练器

**中文** · [English](README.en.md) · [日本語](README.ja.md)

单文件网页版德州扑克练习册，手机上打开就能刷题。

👉 **[在线体验](https://youkou970701.github.io/poker-trainer/)**（支持中文 / English / 日本語）

- **数学直觉**：底池赔率、outs、MDF
- **翻前开池**：各位置该不该开池
- **短码推挤**：短筹码推挤/弃牌判断
- **范围表**、**术语闪卡**、**统计**

纯静态，一个 `index.html`，无依赖、无后端。直接双击打开，或部署到任意静态托管。
