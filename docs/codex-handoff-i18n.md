## 要求

1. **三种语言**：`zh-CN`、`en`、`ja`。默认按 `navigator.language` 选：`zh` 开头用中文，`ja` 开头用日文，其余用英文。顶部放语言切换（`中文 / EN / 日本語`），选择存进 localStorage（键名 `pokerLang`），切换后立即重新渲染当前模块。`<html lang>` 和 `<title>` 跟着变。
2. **文案集中**：所有界面文字（模块名、按钮、题干、反馈、说明段落、统计页）放进同一个文件里的一份字典，三种语言同一组 key。
3. **术语表 `TERMS` 要整体翻译**，而不只是界面：
   - 英文：术语用英文扑克圈通行说法（preflop、pot odds、c-bet、VPIP…），解释用简单英语
   - 日文：用日本扑克圈通行的片假名说法（プリフロップ、ポットオッズ、アウツ、Cベット、VPIP…），解释用「です・ます」体
   - 每条术语加一个**稳定 id**（例如 `'pot-odds'`），三种语言共用
4. **两个会被翻译弄坏的地方，必须改**：
   - `tScore`（localStorage `pokerTerms`）现在用**中文术语名**当 key，切换语言后进度会全部丢失。改成用稳定 id 当 key，并且**迁移老数据**：读到旧的中文 key 时，按中文名映射到 id，迁移后写回。已有用户的「已掌握」数量不能变
   - 术语闪卡的 `bind()` 用 `$('rv').textContent==='显示术语'` 判断正反向，文案一翻译就失效。改成存在 `state` 里（例如 `state.rev`）
5. **错题记录**：`stats[mod].miss` 现在存的是拼好的中文字符串。改成存结构化数据（模块、手牌、位置、筹码深度、术语 id 等），显示时再按当前语言拼。旧的字符串记录原样显示即可，不用迁移
6. **不变的东西**：牌面写法（AKs、77、T9o）、位置缩写（UTG/HJ/CO/BTN/SB/BB）、`bb` 单位、所有范围数据和判题逻辑都不改；`pokerStats` 的统计数字不能丢
7. 字体栈加上日文字体：`"Hiragino Sans","Yu Gothic"`

## 测试

仓库里还没有测试。新增 `scripts/check-i18n.mjs`（Node 直接跑，不加依赖），从 `index.html` 里提取字典和 `TERMS` 后检查：
